## Installation

1. Clone the repository.
2. In the `backend` directory, run `npm install`.
3. Configure the backend `.env` file.
4. Set up the PostgreSQL database.
5. Start the backend using `npm run dev` (in the `backend` directory).
6. In the `frontend` directory, run `npm install`.
7. Start the application using `npx expo start -c` (in the `frontend` directory).
